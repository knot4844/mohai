## 오류 주입 검사

중복ID, 끊긴 참조, 잘못된 상세 타입, 잘못된 관계 대상, 포함 순환, 음수 가격, 범위 밖 좌표, 미등록 열, 잘못된 날짜·시간대·종료 역전, 누락/변조된 근거, 원본 해시 변경, 가짜 종료시각, 일정·분류·요금 원문 변조를 검사했다. 실패 자료는 출력 전 검증에서 차단한다.

취소·자정 넘김·false/unknown/not_applicable/conflict는 실제 출력과 분리한 합성 테스트로 확인했다. false와 not_applicable이 실제 표본에서 확인됐다는 뜻은 아니다. 잘못된 SQL 적재 시 기존 결과 파일이 유지됨을 확인했으며, 일반적인 객체 병합/분리 엔진과 운영 릴리스 롤백은 아직 구현하지 않았다.

## 남은 작업과 다음 순서

1. 표본의 proposed 포함관계와 held 개최 구역을 원문별로 재검토한다.
2. 고정된 표본 ID 목록을 전체 자료의 identity ledger로 확장한다. 새 원본의 회차 추가·삭제·재정렬을 자동으로 같은 ID에 연결하지 않는다.
3. 기존232 행사·장소·상설4·보관 API87의 그림자 이관을 수행하고 모든 원천행의 신규/대응/보류/오류를 보고한다.
4. 일반 병합·분리·공개 snapshot 전환/복구와 공급자별 권한 정책을 구현·검증한다.
5. 그 결과를 바탕으로 운영 DB와 제한 수집 범위를 결정한다. 다음 행동 추천은 그 이후다.

이번 작업은 표본 구조 검증의 완료이며, 전체 이관·대량 수집 준비 완료 판정은 아니다. 새로 받을 API 키 없이 기존 자료로 실행했다.
